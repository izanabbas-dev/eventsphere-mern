# Project: EventSphere Management (MERN, 4th semester student project)

## Tech
- Backend: Node.js + Express + MongoDB (Mongoose)
- ES Modules ("type": "module"), always use .js extension in imports
- Folder structure: config, models, controllers, routes, middleware, validators, utils, scripts (no src folder)
- Server runs on port 3000

## Coding style
- Keep the code simple and readable, at a student level. Do not over-engineer.
- Use clear variable and function names.
- Keep comments few and short. Do not comment every line.
- Avoid advanced patterns unless they are really needed.

## Workflow
- Work on one file or one feature at a time. Do not build the whole project at once.
- After each file, give me a short explanation in simple Roman Urdu so I can understand it.
- Ask me before installing any new package.
- Ask me before deleting or rewriting existing files.
